### How this file was identified

Provenance was not written down when the reference page was built. It was
recovered rather than assumed: the file matched no Poly Haven entry on a first
pass, so it was decoded to a tonemapped equirect, correlated against the preview
images of all 96 assets in Poly Haven's `studio` category (`studio_small_09`
scored 0.91, next best 0.65), and then confirmed exactly on both byte size and
md5 against the API. Recorded here so nobody has to do that twice.

## three.js

`hero-object.js` is written against three.js r128 and uses `RGBELoader`,
`EffectComposer`, `RenderPass`, `ShaderPass`, `BokehPass` and
`GammaCorrectionShader` from the `examples/js` tree. three.js is MIT,
Copyright 2010-2026 three.js authors.
<https://github.com/mrdoob/three.js/blob/dev/LICENSE>

The library is loaded from a CDN at runtime and no part of it is redistributed
in this kit.
