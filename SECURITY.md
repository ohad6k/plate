# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting on this repository: open the **Security** tab and choose **Report a vulnerability**. That form is the supported private channel; it opens a draft advisory visible only to you and the maintainer.

Please do not open a public issue, a pull request or a discussion for a security problem before it is fixed.

Useful reports include the Plate version (`plate --version`), the Python version and operating system, the exact tool call or command, what happened, and what you expected. A minimal reproduction helps more than anything else. Never include a licence key, an access token or other credentials in a report; redact them first.

Expect an acknowledgement within a few days. This is a small project with one maintainer, so please allow reasonable time for a fix before any public disclosure, and tell us if you plan to disclose on a schedule.

## Scope

In scope: the MCP server and its tools, the CLI, the packaging and installation path, and the local capture browser.

Particularly interesting:

- Any path outside the intended directory being read or written by a tool argument.
- `plate_capture` reaching a non-local origin, reusing a real browser profile, or exposing session state.
- Anything that causes a licence key or the contents of `PLATE_HOME` to be printed, logged or transmitted anywhere except the licence check to Polar.
- Archive or input handling that escapes its extraction directory, follows a link out of it, or exhausts memory or disk.

Out of scope: the design quality of anything an agent produces, the availability or content of third-party asset sources (Poly Haven, Google Fonts, the Quaternius library), vulnerabilities in your own agent or model provider, and reports generated by an automated scanner with no demonstrated impact.

## What Plate does with your data

Plate runs locally. It does not upload your project, your code or your captures. Asset resolution queries public asset APIs. Capturing a local project can also load that project's public fonts, scripts and media. The licence check sends a key you entered yourself to Polar and nothing else. Captures and cached metadata stay in `PLATE_HOME` (`~/.plate` by default).
